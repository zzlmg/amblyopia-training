# 太阳花弱视训练（Sunflower Eye）

> 让每一双眼睛都看见清晰的世界 —— 公益免费 · 无广告 · 家庭可执行的弱视视觉训练网站

面向 **3-12 岁弱视儿童及其家长** 的纯前端视觉训练平台，覆盖 5 个临床训练阶段、24 款小游戏，含训练路径测评、训练进度追踪与 PWA 离线应用能力。全部免费、无广告、不收集个人隐私数据。

---

## 功能特点

- **5 阶段临床训练路径**：单眼基础 → 视觉提升 → 脱抑制 → 精细辨别 → 立体视巩固，每阶段有明确的进阶信号
- **24 款训练小游戏**：打地鼠、舒尔特方格、双眼探点、融色大师、葵神辨向、拥挤挑战、浮出来的形状等
- **训练路径测评**：5 道问卷题（年龄/弱视类型/视力/治疗史/红蓝眼镜）智能推荐训练起点
- **训练进度追踪**：本地存档（localStorage）记录成绩、连续打卡、成就系统
- **PWA 离线应用**：安装后像 APP 一样使用，离线可用
- **红蓝眼镜支持**：S3 脱抑制阶段游戏（如双眼探点）支持红蓝 anaglyph 立体训练
- **纯静态零依赖**：单文件 HTML，无外部依赖，隐私友好，任意静态托管即开即用

## 技术架构

| 模块     | 说明                                                |
| ------ | ------------------------------------------------- |
| 前端     | 纯 HTML + CSS + JavaScript（无框架、无外部依赖）              |
| 数据存储   | localStorage（`amblyopia_progress`），无后端、无账号        |
| 离线能力   | Service Worker（`sw.js`，版本化缓存，cache-first + 运行时缓存） |
| PWA 清单 | `manifest.json`（standalone 模式，可添加到主屏幕）            |
| 部署     | 任意静态托管：GitHub Pages / CloudStudio / nginx 等       |

## 快速开始

### 本地体验

直接用浏览器打开 `index.html` 即可，无需构建、无需服务器。

### 部署到 GitHub Pages

1. 将本目录全部内容推送至 GitHub 仓库
2. 仓库 Settings → Pages → 选择分支 `main` + 根目录（`/`）
3. 保存后访问 `https://<用户名>.github.io/<仓库名>/`

> `.nojekyll` 已包含，避免 Jekyll 处理；`start_url: "./"` 支持子路径部署。

### 安装为 APP（PWA）

- **iPhone**：Safari 打开 → 分享 → 添加到主屏幕
- **Android**：Chrome 打开 → 菜单 → 添加到主屏幕

## 5 阶段训练路径

| 阶段      | 目标            | 代表游戏              |
| ------- | ------------- | ----------------- |
| S1 单眼基础 | 遮盖健眼，弱视眼单独练   | 打地鼠、打苍蝇、连连看、走迷宫   |
| S2 视觉提升 | 干扰背景下看得稳      | 舒尔特方格、追光点、找不同     |
| S3 脱抑制  | 双眼开始合作        | 双眼探点、融色大师、电击蓝莓    |
| S4 精细辨别 | V1 皮层 + 对比敏感度 | 葵神辨向、芦荟探踪、拥挤挑战    |
| S5 立体巩固 | 立体深度 + 防复发    | 浮出来的形状、谁在前谁在后、玩具箱 |

训练建议：每天 10-15 分钟，遵医嘱遮盖，每次训练后远眺休息。
